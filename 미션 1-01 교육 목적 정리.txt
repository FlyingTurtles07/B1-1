미션 1-01 교육 목적 정리

이 미션은 단순히 **"ChatGPT를 써보는 방법"**을 배우는 것이 아닙니다.

핵심 목적은 **"AI를 업무 자동화 도구로 활용하기 위한 프롬프트 엔지니어링 전 과정을 경험하는 것"**입니다.

교육과정 관점에서 보면 이 미션은 아래의 흐름으로 설계되어 있습니다.

# AI 업무 자동화 프롬프트 엔지니어링 교육과정

## 1장. 왜 프롬프트를 배워야 하는가

### 학습 목적

AI가 똑똑한 것이 아니라 **질문을 얼마나 잘 설계했는지**에 따라 결과가 달라진다는 것을 이해한다.

### 배우는 내용

* ChatGPT가 항상 좋은 답을 주지 않는 이유
* 같은 AI인데 사람마다 결과가 다른 이유
* 프롬프트 엔지니어링의 필요성
* 업무에서 AI를 사용하는 방식

### 핵심 개념

* AI는 명령을 수행하는 도구
* 좋은 질문 = 좋은 결과
* AI는 검색엔진이 아니다.

---

# 2장. LLM(대규모 언어모델)의 동작 원리 이해

### 학습 목적

AI가 어떻게 답변을 생성하는지 이해하여
환각(Hallucination)이 발생하는 이유를 설명할 수 있다.

### 배우는 내용

#### 1. LLM이란

* GPT
* Claude
* Gemini
* Llama
* Qwen

등이 무엇인지

#### 2. 확률적 생성

AI는

> "정답을 찾는 프로그램"

이 아니라

> "다음 단어가 올 확률을 계산하는 모델"

이라는 점

#### 3. 왜 환각이 발생하는가

예를 들어

```
없는 법률
없는 논문
없는 통계
```

를 그럴듯하게 만들어내는 이유

#### 4. AI의 한계

* 최신 정보 부족
* 계산 실수
* 논리 오류
* 긴 문맥 손실

---

# 3장. 다양한 LLM 비교하기

### 학습 목적

AI를 느낌으로 선택하지 않고
평가 기준을 만들어 비교하는 방법을 배운다.

### 배우는 내용

동일한 질문을

* GPT
* Claude
* Gemini

등에게 입력한다.

비교 항목

* 정확성
* 자연스러움
* 속도
* 긴 문맥 유지
* 형식 준수
* 비용
* API 활용성

등을 점수화한다.

### 최종 학습

왜 특정 모델을 선택했는지 근거를 설명할 수 있어야 한다.

---

# 4장. 업무 자동화 과업 정의

### 학습 목적

AI에게 맡길 업무를 명확하게 정의하는 방법을 배운다.

### 배우는 내용

예시

* 이메일 작성
* 회의록 요약
* 보고서 작성
* 요구사항 정리
* 일정 관리

### 반드시 정의해야 하는 것

* 누가 사용하는가
* 어떤 입력을 받는가
* 어떤 출력을 원하는가
* 출력 형식
* 금지사항

---

# 5장. 입력 템플릿 설계

### 학습 목적

누구나 동일한 품질의 결과를 얻을 수 있도록
재사용 가능한 프롬프트를 만든다.

### 배우는 내용

예를 들어

```
목적

대상

핵심 내용

톤

금지어

반드시 포함할 내용
```

처럼 입력 양식을 만든다.

이 과정을 통해

**"잘 만든 입력 양식 하나가 업무를 자동화한다."**

는 것을 배우게 된다.

---

# 6장. AI 페르소나 설계

### 학습 목적

AI가 어떤 전문가처럼 행동해야 하는지를 설계한다.

### 배우는 내용

예시

```

직무

전문분야

말투

우선순위

금지사항
```

예)

프로젝트 매니저

↓

회의록 전문가

↓

요구사항 분석 전문가

↓

HR 컨설턴트

등

---

# 7장. 시스템 프롬프트 작성

### 학습 목적

AI의 행동 원칙을 정한다.

### 배우는 내용

시스템 프롬프트에는

* 역할
* 목표
* 출력 형식
* 규칙
* 안전장치
* 확인 질문
* 근거 제시

등을 넣는다.

즉,

AI의 운영체제를 만드는 과정이다.

# 8장. Few-shot Prompt 설계

### 학습 목적

예시를 통해 AI에게 원하는 답변 방식을 학습시킨다.

### 배우는 내용

최소 3개의 예시 작성

예시

좋은 입력

↓

좋은 출력

↓

패턴 학습

또한

모호한 질문에서는

AI가

```
추측하지 않고
되물어보도록
```

설계한다.

---

# 9장. 프롬프트 개선(v1 → v2)

### 학습 목적

좋은 프롬프트는 한 번에 완성되지 않는다는 것을 배운다.

### 배우는 내용

v1

```
회의록 요약해줘
```

↓

문제 발견

↓

v2

```
결정사항

Action Item

리스크

확인 질문

템플릿

근거

출력
```

처럼 개선한다.

여기서

Prompt Engineering의 핵심인

**반복 개선(Iteration)**

을 경험한다.

---

# 10장. 단계적 추론(Reasoning Prompt)

### 학습 목적

AI가 바로 답하지 않고
생각하는 순서를 설계한다.

### 배우는 내용

예)

1.

요구사항 분석

↓

2.

정보 부족 확인

↓

3.

추가 질문

↓

4.

답변 작성

↓

5.

검토

↓

6.

최종 출력

단,

최종 사용자에게는

생각 과정을 모두 보여주지 않는다.

---

# 11장. 환각(Hallucination) 검증

### 학습 목적

AI의 답변을 믿지 않고 검증하는 습관을 기른다.

### 배우는 내용

질문 5개 이상 준비

예)

* 법률
* 정책
* 계산
* 날짜
* 수치

각 질문마다

* 기대 정답
* 근거
* 출처
* Pass 기준
* Fail 기준

을 만든다.

즉,

AI를 테스트하는 방법을 배우는 과정이다.

---

# 12장. 문맥 유지(Context Management)

### 학습 목적

AI가 긴 대화에서도 이전 내용을 기억하도록 활용하는 방법을 배운다.

### 배우는 내용

10턴 이상의 대화 수행

중간에

* 조건 변경
* 대상 변경
* 톤 변경
* 새로운 정보 추가

등을 수행한다.

AI가

기존 조건은 유지하고

변경된 내용만 반영하는지 확인한다.

---

# 13장. 프롬프트 디버깅

### 학습 목적

문제가 생겼을 때 원인을 찾아 개선하는 능력을 기른다.

### 배우는 내용

대표적인 문제

* 환각 발생
* 형식 깨짐
* 문맥 손실
* 출력 누락
* 추측

각 문제를

원인 분석

↓

프롬프트 수정

↓

재실행

↓

비교

과정으로 해결한다.

---

# 14장. 업무 자동화 패키지 완성

### 학습 목적

지금까지 만든 내용을 하나의 재사용 가능한 시스템으로 완성한다.

### 산출물

① 모델 비교 보고서

② 시스템 설계 문서

③ 실행 로그

④ 최종 프롬프트

⑤ 입력 템플릿

⑥ 테스트 케이스

⑦ 개선 이력

---

# 15장. 실제 업무 적용 및 확장

### 학습 목적

완성한 프롬프트를 다양한 업무에 재사용하고 확장하는 방법을 익힌다.

### 배우는 내용

* 커스텀 GPT 또는 에이전트 형태로 재사용
* 다른 업무(보고서, 이메일, 고객 응대 등)로 프롬프트 확장
* 멀티모달 AI와 연계하여 문서와 시각 자료를 함께 생성
* 지속적인 테스트와 개선으로 업무 자동화 품질 향상

---

# 이 미션의 핵심 학습 흐름

```text
① LLM 이해
        ↓
② 여러 AI 비교
        ↓
③ 업무 정의
        ↓
④ 입력 템플릿 작성
        ↓
⑤ 페르소나 설계
        ↓
⑥ 시스템 프롬프트 작성
        ↓
⑦ Few-shot 예시 작성
        ↓
⑧ 단계적 추론 적용
        ↓
⑨ 환각 검증
        ↓
⑩ 10턴 이상 대화로 문맥 유지 확인
        ↓
⑪ 프롬프트 개선(v1 → v2)
        ↓
⑫ 업무 자동화 프롬프트 패키지 완성
```

## 이 미션이 궁극적으로 알려주려는 것

이 미션의 가장 중요한 목표는 **"AI에게 질문하는 법"**을 배우는 것이 아니라, **업무를 분석하고 AI가 안정적으로 수행할 수 있도록 설계·검증·개선하는 전 과정을 익히는 것**입니다. 다시 말해, 하나의 프롬프트를 만드는 수준을 넘어 **모델 선택 → 업무 정의 → 프롬프트 설계 → 예시 학습(Few-shot) → 단계적 추론 → 환각 검증 → 반복 개선 → 문맥 유지 검증**까지 포함하는 **AI 업무 자동화 시스템을 설계하는 방법론**을 체득하는 것이 이 미션의 핵심입니다. 이를 통해 학습자는 AI를 단순한 대화 상대가 아니라, 재현 가능하고 신뢰할 수 있는 업무 파트너로 활용하는 역량을 갖추게 됩니다.
